One job title, 44 characters, for the Weirdest Job Title blind-judge showdown: **Professional Mourner for Strangers' Funerals**. Professional mourners are a real job — and this one is hired to weep for people they never met, which is the whole point of the hire. A real-sounding job with one hilariously specific twist.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` with exactly that title (standard library only, deterministic), then reads it back and validates it: UTF-8, 1–60 characters, not only whitespace.
